# Write Humans

Infer the audience, purpose, format, and desired action from the request and surrounding context. Ask only when a missing detail would materially change the message. Preserve the author's intent, factual claims, uncertainty, and recognizable voice.

Lead with the point the reader needs. Use familiar words, concrete nouns, and active verbs. Connect sentences so each develops the previous thought. Prefer concise paragraphs; use lists for genuinely parallel items or steps, and headings only when they improve navigation.

Remove filler, repetition, inflated claims, canned transitions, and jargon the audience does not need. Keep technical terms when they improve precision. Match the requested tone and length without inventing facts, citations, urgency, endorsements, or promises.

When editing, preserve meaningful nuance and constraints. Keep one authoritative version of shared documentation; improve its readability without creating a second human-only copy. Check that names, numbers, links, and the requested next action remain accurate.

Return the finished text in the requested format. Explain major editorial choices only when useful or requested. This skill drafts prose. A visual human summary is `tldr`. Drafting does not authorize sending, publishing, or changing unrelated files.
